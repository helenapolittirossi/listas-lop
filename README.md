# README

## Como executar os programas

Para executar os programas deste projeto, é necessário utilizar o **Embarcadero Dev-C++**.

### Passo a passo

1. Abra o **Embarcadero Dev-C++**.
2. Copie o código do programa que deseja executar.
3. Cole o código no editor do **Embarcadero Dev-C++**.
4. Salve o arquivo, se necessário.
5. Pressione **F11** para compilar e executar o programa.

> **Observação:** Certifique-se de que o código foi copiado corretamente antes de pressionar **F11**.
